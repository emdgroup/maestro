In-project header: Home / connection / project
  • House: back to Home, releases the project lock. Amber dot while another project needs you; the tooltip names it.
  • Connection menu: every connection. Hovering, clicking or pressing Right on one opens a side panel of its projects as small tiles, needs-you first, then Add project.
  • Project menu: this connection's projects as rows, the current one checked, then Add project.
  • Opening a project on another connection releases the lock on this one; the side panel says so.
